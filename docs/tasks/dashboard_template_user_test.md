## 1. まず画像を含む1件を Tableau で確認

`tmp/dashboard-template-validation/user-checks/01-customer-support.twbx` を Tableau で開く。
ダッシュボードタブ **Template user check** を表示し、次の内容を確認する。

1. 構造・データ参照・画像欠落のエラーが出ない。
2. 上部820pxがテンプレート領域。ロゴ画像、ヘッダーの文字・色・余白が元の Customer Support Cases と対応している。
3. 元のシートは「グラフ」、パラメーター操作は「パラメーター」の文字枠になり、元の位置・寸法で中央に表示されている。
4. テンプレート領域の下に生成したフィルター、KPI カード、棒グラフがある。上部の「グラフ」枠も残っている。
5. 下部の棒グラフを選択し、生成側のフィルターアクションが動作することを確認する。

元の3つの TWBX は比較用に開くだけにし、保存・上書きしない。確認用ファイルの Tableau Public への公開も不要。

## 3. HTML を直接開いて選択を確認（サーバー不要）

`tmp/dashboard-template-validation/config.html` を Chrome または Edge で直接開く。

1. デザインルールのテンプレート欄で `customer-support` を選ぶと、単一の Customer Support Cases が選ばれる。
2. `funnel` には2件、`viz-extensions` には22件のダッシュボードが選べる。
3. デザインのプリセットを変更しても、テンプレートと内部ダッシュボードの選択が残る。
4. ダッシュボードタブでグラフ・KPI カードの設定を引き続き編集できる。
5. ダッシュボードタブの YAML 出力で、`design.dashboard_template` と `design.dashboard_template_dashboard` が選んだ値になっている。未使用を選ぶと両キーが出力されない。

復元の確認用ファイルも用意してある。

| HTML | 期待する表示 |
|---|---|
| `config.html` | customer-support / Customer Support Cases と通常生成の設定が復元される |
| `config-network-restored.html` | viz-extensions / Network が復元される。実際の ID は末尾に空白2個がある `Network  `。出力 YAML でも空白が残る |
| `config-missing.html` | 存在しない選択が「見つかりません」と表示され、勝手に別の選択にならない |

ダウンロードした YAML の往復を確認する際は、その YAML をこのチャットへ添付するか保存先を伝えてください。同じ検証用 template_root を指定して HTML を再出力し、選択とグラフ設定を照合する。
