# タスク: 設定を画面で行う仕組み（HTML 出力 → 設定ファイル）

- 起票日: 2026-09-05
- 対象: `docs/backlog.md` の J-1 / J-2 / J-3
- **範囲: a（フィールドの表示名・フォルダ割り当てのみ）**

## 目的

ダッシュボードを組む前に、データソースのフィールドを調べて Python コードへ手で書き写す作業が
発生している。フィールドが数十個あると現実的でない。
**HTML を出力し、画面で設定して設定ファイルを吐かせる**ことでこれを置き換える。

## 想定する流れ

```
1. Python  : wb.export_html("fields.html")
2. ブラウザ : fields.html を開き、表示名とフォルダを画面で編集
3. ボタン   : fields.yaml をダウンロード
4. Python  : datasource.apply_field_config("fields.yaml") → wb.save(...)
```

## 既にある部品

| 部品 | 場所 | 役割 |
|---|---|---|
| `TwbWorkbook.export_json()` | `twbpatch/workbook.py` | ワークブックの内容を辞書で取り出す |
| `serialize_workbook()` | `twbpatch/serialization.py:76` | 上記の実体 |
| `TwbDatasource.apply_field_config()` | `twbpatch/connected.py` | 表示名とフォルダを一括適用する |
| `TwbWorkbook.apply_field_config()` | `twbpatch/workbook.py` | ワークブック単位の同処理 |
| `ec_site_fields.yaml` | リポジトリルート | 設定ファイルの実例 |

**読み出しと書き戻しは実装済み。作るのは真ん中だけ。**

## 制約

- **外部依存を増やさない。** 現在の依存は `lxml` と `PyYAML` のみ。
  HTML は文字列として生成し、CSS と JavaScript はインラインに埋め込む。
  テンプレートエンジンも CDN も使わない（オフラインで開けること）。
- **サーバを立てない。** ブラウザからのダウンロードで設定ファイルを受け渡す。
- 出力した HTML は単体で完結し、他のファイルを参照しない。

## Phase 2: 画面で設定して出力（J-2 / 範囲 a）

- [ ] **J2-1** 画面仕様を決める
  - 各フィールド行に「表示名」の入力欄と「フォルダ」の選択欄を置く
  - 初期値は現在の設定を入れておく（変更しない項目はそのまま出力される）
- [ ] **J2-2** フォルダの新規追加をできるようにする
- [ ] **J2-3** 画面側でバリデーションする
  `apply_field_config()` が例外にする条件を、出力前に画面で防ぐ。
  - フォルダ名が空 → `ValueError`
  - 表示名が空 → `ValueError`
  - **同じフィールドを 2 つのフォルダに割り当て** → `ValueError`
    （`connected.py` の `field is assigned more than once`）
- [ ] **J2-4** YAML のダウンロードを実装する
  - `Blob` + `<a download>` で保存させる
  - ファイル名の既定値を決める
- [ ] **J2-5** 往復テストを書く
  - 出力 → 想定される YAML → `apply_field_config()` → 期待どおりに表示名とフォルダが変わる
  - **ブラウザ操作は自動テストしない。** YAML を入力とした Python 側のテストで担保する

**完了条件**: 画面で編集して落とした YAML を `apply_field_config()` に渡すと、
意図どおりワークブックが更新される。
