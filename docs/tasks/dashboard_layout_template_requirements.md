# ダッシュボードレイアウトテンプレート 要件メモ

## 目的

Tableau で作成したダッシュボードの見た目を、twbpatch で作るダッシュボードへ適用できるようにする。テンプレートからデータソースやワークシート定義を持ち込まず、レイアウトと静的なデザイン要素を再利用する。

## テンプレートの配置と選択

- テンプレートは次のフォルダ構成で管理する。

  ```text
  template/
    dashboard_template/
      <テンプレート名>/
        template.twb または template.twbx
  ```

- 各テンプレート名フォルダには、`template.twb` または `template.twbx` を1つ置く。
- テンプレートはデザインルール側で選択する。
- YAML にはテンプレート名（フォルダ名）を記録する。
- テンプレート Workbook にダッシュボードが複数ある場合は、適用するダッシュボードも選択し、YAML に記録する。
- `.twb` と `.twbx` の両方を選択できる。
- テンプレートを選択しない場合は、現在のダッシュボード作成動作を維持する。

## 取り込む要素

- ダッシュボードのコンテナ階層、配置、サイズを保持する。
- 静的なテキストオブジェクトと画像を保持する。
- `.twbx` 内にある画像もテンプレートの一部として扱う。
- ワークシートの配置枠は、元の位置とサイズを保ったテキストボックスへ置き換え、「グラフ」と中央に表示する。
- フィルターの配置枠は、元の位置とサイズを保ったテキストボックスへ置き換え、「フィルター」と中央に表示する。
- パラメーター操作の配置枠は、元の位置とサイズを保ったテキストボックスへ置き換え、「パラメーター」と中央に表示する。

## 取り込まない要素

- データソース定義、ワークシート定義、抽出データなど、テンプレート元 Workbook のデータ関連内容。
- ワークシート、フィルター、パラメーター操作そのもの。上記のとおり、これらはラベル付きテキストボックスに置き換える。
- 凡例およびダッシュボードアクション。
- その他の未対応または対象外のオブジェクト。警告は表示しない。

## 適用方法

- 元 Workbook のダッシュボードをそのまま複製せず、必要なレイアウト要素を読み取り、適用先で再構成する。
- テンプレートのデータ参照は適用先へ持ち込まない。
- テンプレートから新しいワークシートは作成しない。
- ツール側では、従来どおりグラフや KPI カードを指定・生成できる。テンプレートの利用と併用する。
- 「テンプレートからワークシートを作成しない」は、元テンプレートのシート定義・グラフ内容を移植しないという意味であり、ツール側のグラフ生成を制限しない。
- ツール側のグラフ・KPI カードについて、テンプレート内の「グラフ」の文字枠を配置先として選ぶ機能は不要とする。
- ツール側で指定・生成したグラフや KPI カードは、ダッシュボードテンプレートの領域の下に追加する。
- テンプレートの「グラフ」「フィルター」「パラメーター」のテキストボックスはそのまま残し、生成内容への置き換えや対応付けは行わない。
- テンプレートの領域内は元のレイアウトを保持する。ツール側の生成内容は従来の作成設定による位置・サイズ・配置設定を使い、テンプレート領域の高さ分だけ下へ移動する。

## 未確定事項

- テキストオブジェクトにデータ参照や動的な値が含まれる場合の扱い。
- `.twb` が参照する外部画像を、テンプレートフォルダ内からどのように解決するか。
- YAML に保存されたテンプレート名やダッシュボード名が見つからない場合のエラー表示。
