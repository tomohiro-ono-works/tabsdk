# GUI 利用ガイド

ランチャーのファイル選択画面と、ブラウザーで開く設定画面を使う手順です。
Python のコードを書く必要はありません。
初めて使う場合は[初期セットアップ](../../setup/windows_setup.md)を済ませてください。

## 起動とメニュー

`scripts/tabsdk.bat` をダブルクリックして起動します。
処理が終わってランチャーが閉じたら、次の操作のためにもう一度起動します。

| メニュー | 選ぶファイル | 結果 |
|---|---|---|
| 1 | 元の `.twb` / `.twbx` | 同じフォルダーに `<元の名前>_config.html` を出力し、ブラウザーで開く |
| 2 | 設定 `.yaml` / `.yml`、元の `.twb` / `.twbx` | 設定を反映した `<元の名前>_config.html` を出力し、ブラウザーで開く。Workbook は保存しない |
| 3 | 設定 `.yaml` / `.yml`、元の `.twb` / `.twbx` | 同じフォルダーに `<元の名前>_dashboard.twb` を出力する。Tableau で開くか選べる |
| 4 | 元の `.twb` / `.twbx` | 同じフォルダーに `<元の名前>_definition.xlsx` を新規作成して開く |
| 9 | なし | 終了 |

メニュー 1・2 は同じ名前の HTML、メニュー 3 は同じ名前の出力 TWB を上書きします。
メニュー 4 は既存の Excel を上書きしません。

## 設定画面からダッシュボードを作る

1. メニュー **1** で元の Workbook を選びます。
2. 開いた HTML のデータソース、デザインルール、ダッシュボード、KPI ツリーを設定します。
3. 作りたいダッシュボードまたは KPI ツリーのタブで「設定 YAML をダウンロード」を押します。
4. ランチャーを起動し直し、メニュー **3** でダウンロードした YAML、元の Workbook の順に選びます。
5. 出力された TWB を Tableau で確認します。

ダッシュボードの YAML は `twbpatch_dashboard.yaml`、KPI ツリーの YAML は
`twbpatch_kpi_tree.yaml` です。どちらもデザインルールとデータソースの設定を含みます。
HTML はオフラインで開けます。設定の反映には、ダウンロードした YAML をランチャーへ渡します。

## 計算フィールドを作ってからグラフに使う

計算フィールドは、元の Workbook に存在するようにしてからグラフの候補へ出します。
次の順に操作してください。

1. メニュー **1** で元の Workbook を選びます。
2. データソースのタブで計算フィールドを作り、「設定 YAML をダウンロード」で `twbpatch_datasources.yaml` を保存します。
3. メニュー **2** でこの YAML と元の Workbook を選びます。
4. 再出力された HTML で、計算フィールドをグラフや KPI の項目として選びます。
5. ダッシュボードまたは KPI ツリーのタブから YAML をダウンロードします。
6. メニュー **3** で最後の YAML と元の Workbook を選び、TWB を作成します。

メニュー 2 はメモリ上で計算フィールドを反映して画面を再出力します。
再出力前の HTML は使い回さず、ブラウザーで新しい内容を開いてください。
生成済みのダッシュボードへ同じ YAML を再適用すると、シート名の重複で停止するため、元の Workbook を選びます。

## テンプレートと AI 用ルール

ダッシュボードの見た目を取り込むには、`template/dashboard_template/<フォルダ名>/` に
`template.twb` または `template.twbx` を置き、メニュー 1 で HTML を再出力します。
デザインルールでテンプレートと内部ダッシュボードを選びます。
テンプレートのシートなどは文字枠になり、設定したグラフや KPI カードはその下へ追加されます。
[画像を含む配置手順](../../../template/dashboard_template/README.md)も参照してください。

AI 用プロンプトでは、フィールドの命名・分類用に `template/prompt_rules/`、
計算フィールド用に `template/calc_prompt_rules/` の Markdown を選択できます。
ルールを編集・追加したら HTML を再出力します。
[テンプレート一覧](../../../template/README.md)で各フォルダーの役割を確認できます。

## 定義書を作る

メニュー **4** で Workbook を選びます。7 種類の定義を Excel の各シートへ出力します。
`scripts/04定義書作成用.bat` を直接起動するか、Workbook をその bat にドラッグしても使えます。
取得できない値は空欄になります。
